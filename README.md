# 📈 Business Intelligence Dashboards & Data Pipelines Portfolio

Colección de soluciones avanzadas de **Business Intelligence (BI)**, **Modelado de Datos** y **Analítica Visual** orientadas a transformar datos brutos en insights estratégicos para la toma de decisiones ejecutivas.

La suite combina arquitecturas de modelado en estrella, procesos ETL/ELT optimizados, cálculo de KPIs dinámicos mediante DAX avanzado y visualización interactiva utilizando **Power BI** y **Tableau**.

## ⚙️ Stack Tecnológico & Metodologías

* **Business Intelligence & Dashboards:** Power BI Desktop, Tableau Desktop / Public.
* **Transformación de Datos & ETL:** Power Query (M), Python (Pandas, NumPy).
* **Lenguajes de Consulta & Modelado:** DAX (Data Analysis Expressions), SQL, Esquema Estrella (Star Schema), Tablas de Hechos y Dimensiones.
* **Analítica & EDA:** Python (Jupyter Notebooks), Análisis exploratorio de datos, Forecasting.
